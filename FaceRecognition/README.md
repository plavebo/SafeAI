# Usage
1. Face Recognition 폴더를 전부 다운로드
2. Face Recognition 폴더에 가중치 파일 다운로드 - https://drive.google.com/file/d/1510eaADxBceU7Ac8PP3YuOFs6W5Raz5s/view?usp=sharing
3. Face Recognition 폴더에 Insightface github clone
ex) git clone --depth 1 https://github.com/deepinsight/insightface.git '/path/to/your/FaceRecognition'
4. Face Recognition.ipynb 파일 내 경로 수정
5. 목적에 따라 1장 인식, 여러 장 인식 코드 실행
