# Usage
1. Download the entire **FaceRecognition** folder.
2. Download the model weight file into the **FaceRecognition** folder from the following link:
   - https://drive.google.com/file/d/1510eaADxBceU7Ac8PP3YuOFs6W5Raz5s/view?usp=sharing
3. Clone the InsightFace GitHub repository inside the **FaceRecognition** folder:
   - Example: `git clone --depth 1 https://github.com/deepinsight/insightface.git '/path/to/your/FaceRecognition/insightface'`
4. Update the paths (such as dataset path, model weight path, etc.) inside the **FaceRecognition.ipynb** file.
5. Run the code for either single-image recognition or multi-image recognition, depending on your objective.
